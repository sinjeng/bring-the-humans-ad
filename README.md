# Bring the humans — ad page for make.fun

An ad page for [make.fun](https://make.fun), built for the
[Bring the humans](https://make.fun/bounty/bring-the-humans-01) bounty.

`index.html` is the ad: one file, no build step, no framework, no external
files. Colours, type and the lockup follow the make.fun press kit
(https://make.fun/press, edition 2026-11-02).

`ad.png` is a headless-Chromium screenshot of that page at 1280x800.
